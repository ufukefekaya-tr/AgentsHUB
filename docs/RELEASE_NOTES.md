# 🤖 AgentsHUB v2.0.0-beta — First Public Release

**AgentsHUB** is an open-source Agentic OS that runs autonomous AI agents entirely on your PC.

## ✨ Highlights

- 🧠 **29 Built-in Skills** — File operations, web search, Python, email, GitHub, image generation, and more
- 🧬 **Kaizen Engine** — Autonomous self-learning from every conversation
- 🔐 **Privacy-First** — All data stays on your local machine, nothing sent to cloud
- 💬 **Multi-Agent System** — Create unlimited agents with unique DNA, rules, and skills
- 📱 **Telegram Integration** — Control agents remotely from your phone
- 🧠 **3-Layer Memory** — RAM + SQLite/Vector + Google Cache
- 🛡️ **Enterprise Security** — CyberShield, Path Guard, Sandbox Runner, Circuit Breaker
- 🎨 **Google Imagen** — AI image generation built-in
- ⚡ **Zero-Config Install** — Double-click START.bat or run setup.exe

## 💰 Free for 1 Year

New Google Cloud users get **$300 in free credits** = ~1 year of AI usage at no cost.

## 🚀 Quick Start

1. Download this release (ZIP or setup.exe)
2. Double-click `START.bat` (or run the installer)
3. Open `http://localhost:3434`
4. Paste your [Google AI Studio API Key](https://aistudio.google.com)
5. Create an agent and start using!

## 📋 Requirements

- Windows 10/11
- Node.js v18+ (auto-installed by START.bat)
- Google AI Studio API Key (free)
