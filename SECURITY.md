## Güvenlik Açığı Bildirimi / Reporting a Vulnerability

AgentsHUB'ın güvenliğini ciddiye alıyoruz. Bir güvenlik açığı bulduysanız, lütfen sorumlu ifşa (responsible disclosure) ilkelerini takip edin.

**⚠️ Güvenlik açıklarını asla public Issue olarak açmayın!**

### Nasıl Bildirilir / How to Report

1. **E-posta:** Güvenlik açığı detaylarını **info@agentshub.com.tr** adresine gönderin
2. **Konu satırı:** `[SECURITY] Kısa açıklama`
3. **İçerik:** Açığın detaylı açıklaması, tekrar etme adımları ve varsa PoC (Proof of Concept)

### Beklentiler / What to Expect

- **24 saat:** İlk yanıt alırsınız
- **72 saat:** Açığın doğrulanması ve öncelik belirlenmesi
- **7-14 gün:** Düzeltme yayınlanması (kritiklik seviyesine bağlı)

### Yerleşik Güvenlik Katmanları / Built-in Security Layers

AgentsHUB aşağıdaki güvenlik mekanizmalarıyla donatılmıştır:

- **CyberShield** — AI destekli girdi sanitizasyonu
- **Path Guard** — Sistem dosyalarına yetkisiz erişim engeli
- **Sandbox Runner** — Yetenekler izole ortamda çalışır
- **Circuit Breaker** — Hata durumunda otomatik devre kesici
- **SSRF Koruması** — Sunucu taraflı istek sahteciliği engeli

### Teşekkür / Acknowledgments

Sorumlu ifşa ilkelerini takip eden güvenlik araştırmacılarına teşekkür ederiz.
