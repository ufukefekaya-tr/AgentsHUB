- **💻 byterover** (`byterover.js`): Terminal komutu calistirir veya dosya sistemi operasyonlari (oku/yaz/listele/sil) yapar.
- **🧮 calculator** (`calculator.js`): Matematiksel ifadeleri hesaplar. Desteklenen islemler: toplama (+), cikarma (-), carpma (*), bolme (/), us alma (^), yuzde hesabi (%), karekök (sqrt), trigonometri (sin, cos, tan), logaritma (log, ln), sabitler (pi). Ornek kullanim:

- **📋 clipboard** (`clipboard.js`): Panoya (clipboard) metin kopyalar veya panodan metin okur. Windows PowerShell ile calisir. 
- **🦆 duckduckgo_search** (`duckduckgo_search.js`): DuckDuckGo HTML sürümü üzerinden ücretsiz ve API anahtarsız web araması yapar.
- **🕐 get_server_time** (`get_time.js`): Sunucunun anlik guncel saat ve tarih bilgisini ceker. ISO 8601 formatinda dondurur. Opsiyonel timezone parametresi ile farkli saat dilimlerinde gosterir (ornek: Europe/Istanbul, America/New_York).
- **🔍 google_search** (`google_search.js`): Güncel bilgilere (haberler, hava durumu, hisse senetleri vb.) ulasmak icin Google
- **🛡️ health_checker** (`health_checker.js`): Ajanın kendi veya dış sistem (API/Web) bağımlılıklarının sağlık durumlarını (Ayakta mı?) izler. Hataları ve HTTP kodlarını analiz eder.
- **📄 pdf_extractor** (`pdf_extractor.js`): PDF belgelerini okur, geliştirilmiş metin ayrıştırma (parse) işlemleri yapar ve sayfa limitleriyle çalışır.
- **🐍 python_runner** (`python_runner.js`): Sistemde yerel olarak Python kod blokları çalıştırır, test eder ve console çıktılarını/hataları geri döndürür.
- **📸 screenshot** (`screenshot.js`): Ekran goruntusu alir ve dosya olarak kaydeder. 
- **📡 signal_agent** (`signal_agent.js`): Diğer ajanlarla (Multi-Agent Swarm) iletişim kurar. İş birliği, yetki devri veya bilgi talebi için PING atıp cevap döner.
- **🧠 skill_creator.js** (`skill_creator.js`): Ajanın kendi otonom iş havuzuna dinamik olarak yeni Javascript yetenekleri (skill) yazmasını ve kendi dizinine kaydetmesini sağlar.
- **📊 system_monitor** (`system_monitor.js`): Bilgisayarin sistem bilgilerini getirir: CPU kullanimi, RAM durumu, disk alani, calisan islemler. Windows WMIC ve PowerShell komutlari ile calisir. 
- **🔗 url_opener** (`url_opener.js`): Varsayilan tarayicida bir URL acar. YouTube
